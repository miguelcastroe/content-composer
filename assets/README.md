# Composer assets

Persistent asset library organized by brand.

Each brand contains:
- `products/` — approved packshots and product references
- `logos/` — official brand marks
- `references/` — approved visual references and recurring look-and-feel assets

Composer should reuse these assets before asking for a new upload. When a reusable asset is approved, add it to the relevant brand folder.

Current brands: Nastizol, Probioticos, Colnatur, Anaflex, Ardiles, Yoleit.
