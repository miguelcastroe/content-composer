# Clash Grotesk

This folder is reserved for the locally hosted Clash Grotesk font family used for on-image typography.

Expected weights:

- 200 Extralight
- 300 Light
- 400 Regular
- 500 Medium
- 600 Semibold
- 700 Bold

Until local font files are added, the app loads Clash Grotesk from Fontshare as a temporary fallback source.
